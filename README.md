# WristGPT

Личный помощник для Apple Watch Series 9. Тёмный интерфейс с мятным акцентом, системный ввод текста/диктовка, история текущего диалога, повтор запроса и выбор модели из доступных аккаунту.

## Текущий статус

- Подготовлены исходники iPhone + watchOS и GitHub Actions для сборки без собственного Mac.
- На Windows подготовлена локальная программа Bridge с официальным Sign in with ChatGPT.
- Проверены DPAPI, TLS-сертификат, PKCE/state, защита локальных HTTP-эндпоинтов и обработка успешных/прерванных потоков.
- Компиляция Apple-приложений, вход в настоящий аккаунт, получение ответа от GPT и установка на физические часы требуют отдельных проверок. Не считайте наличие исходников подтверждением установки.

## Что нужно

- Apple Watch Series 9 с watchOS 10+ и парный iPhone с iOS 17+.
- Windows с Python 3.11+ и интернетом. Компьютер должен оставаться включённым при запросах.
- Подписка ChatGPT с доступом к ChatGPT plan usage (по текущей документации подходящие Plus/Pro). Доступность определяется OpenAI после входа и проверки разрешений.
- Бесплатный Apple ID для личной подписи. Платный Apple Developer не обязателен, но бесплатные профили истекают через 7 дней.

## Запустить Windows-программу

1. Откройте `Start-WristGPT.cmd`. При первом запуске создаётся отдельное Python-окружение и устанавливаются зависимости.
2. Откроется <http://127.0.0.1:8765>. Здесь есть интерактивное превью часов и настройки.
3. Нажмите **Continue with ChatGPT**, войдите на официальном сайте OpenAI, выберите аккаунт/пространство и разрешите использование подписки.
4. Вернитесь в панель и нажмите **Проверить**. Подключение подтверждено только после успешной проверки. Для проверки реального ответа в превью отправьте вопрос.

Пароль ChatGPT вводится только на официальном сайте. OAuth-токены остаются на компьютере и зашифрованы Windows DPAPI. Они не передаются на iPhone или часы и не добавляются в GitHub.

## Собрать без собственного Mac

В репозитории откройте **Actions → Build WristGPT for iPhone and Watch → Run workflow**. Сборка выполняется на macOS runner GitHub. Стандартные runner бесплатны для публичных репозиториев, с учётом правил GitHub по хранению артефактов. Приватные репозитории имеют отдельные лимиты.

Скачайте артефакт `WristGPT-unsigned-IPA` и распакуйте `WristGPT-unsigned.ipa`. Он содержит iPhone-приложение и встроенный watchOS-компонент. Это неподписанный пакет; самостоятельно на устройстве он не запустится.

## Установить через Windows

Используется экспериментальная community-ветка iLoader с поддержкой Apple Watch. Обычная установка IPA на iPhone не подтверждает установку watchOS-компонента.

Проверяемый источник: <https://github.com/Rzbck/iloader-watch-companion>

Известная автору рабочая пара:

- iLoader `70f37e9b4afc659ab44ec1944c034093f4cda416`.
- isideload `f7b9f3da570edd6824c29680545e710846d07df5`.
- Сборка Windows: <https://github.com/Rzbck/iloader/actions/runs/34436587217>.
- SHA-256 установщика: `34BB3422BA7983490C501E65D388BD60140F341A708AA75E00FA64D8A9F92B9A`.

Эта ветка не является официальным релизом iLoader. Автор сообщает об успешной физической проверке; совместимость со всеми версиями iOS/watchOS не установлена.

1. Подключите разблокированный iPhone к Windows по USB, подтвердите доверие на телефоне. Часы должны быть связаны с iPhone.
2. Откройте установленный **iLoader**. Вход в Apple ID и двухфакторную проверку выполните самостоятельно в программе. Не присылайте пароль в чат.
3. Выберите iPhone, затем **Import IPA** и `WristGPT-unsigned.ipa`.
4. Следуйте сообщениям программы. Для запуска собственной development-сборки могут понадобиться доверие профилю и Developer Mode на iPhone/часах. Эти действия выполняются на самих устройствах.
5. Убедитесь отдельно: приложение установилось на iPhone, запускается на iPhone, установилось на часах, запускается на часах. Если watchOS-компонент не установлен, зафиксируйте точную ошибку.

Локальная копия экспериментального установщика была установлена в `%LOCALAPPDATA%\Programs\WristGPT-iLoader-Watch\iloader.exe`. Будьте внимательны к обновлениям: обычный upstream-релиз может не содержать экспериментальную поддержку Watch.

Для загрузки приложений из App Store отдельный установщик и Apple Developer не нужны: используйте App Store на часах либо приложение Watch на iPhone.

## Связать с Windows

1. На компьютере в панели WristGPT нажмите **Подключить часы**.
2. Убедитесь, что указан IP домашней Wi-Fi сети. Виртуальные адаптеры/VPN иногда меняют выбранный адрес; его можно исправить в поле.
3. Передайте личный JSON-код на свой iPhone и вставьте в WristGPT → **Подключить Apple Watch**. Код содержит адрес, отдельный секрет этого локального моста и SHA-256 сертификата, а не токен OpenAI.
4. iPhone сохраняет код в Keychain и передаёт его парным часам через Watch Connectivity. Если часы ещё недоступны, откройте приложение на обоих устройствах и повторите отправку.
5. На часах: **… → Проверить**. Должны отобразиться аккаунт и доступные модели.

Мост принимает HTTPS на порту 8443 и требует отдельный секрет подключения. iPhone и Watch принимают только конкретный сертификат с отпечатком из кода. Панель управления доступна только на loopback компьютера (порт 8765), а операции защищены CSRF-проверкой и проверкой Host.

Если связь не устанавливается: проверьте, что устройства видят компьютер в локальной сети, гостевая Wi-Fi сеть не изолирует клиентов, IP не поменялся и Windows Firewall разрешает входящее соединение для процесса Python в частной сети. Программа не отключает брандмауэр и не настраивает проброс портов.

## Ограничения

- Для запросов нужен работающий Windows-мост и доступ к нему по сети. Вне домашней сети этот вариант по умолчанию не работает.
- Текущая история хранится на часах локально; это отдельный диалог, не история чатов ChatGPT.
- Диктовка обеспечивается watchOS. Аудио через интеграцию подписки не отправляется.
- Лимиты подписки общие с другими поддерживаемыми приложениями. Отдельный API-ключ не используется.
- Запрос отправляется после нажатия **Отправить**. UI-пример ответа явно помечен как демонстрационный.
- При переустановке/сбросе Windows-секретов передайте новый код на iPhone и часы.
- Удаление/повторная установка Apple-приложения может удалить историю.

## Разработка на Mac при появлении доступа

Установите Xcode и XcodeGen, выполните `cd Apple && xcodegen generate`, откройте `WristGPT.xcodeproj`. Для обоих targets выберите один **Personal Team** и уникальные связанные Bundle ID. Если изменяете Bundle ID телефона, обновите `WKCompanionAppBundleIdentifier` у Watch target. Используется Swift 5 language mode, минимальные версии iOS 17/watchOS 10.
